# CTF 任务 Skill

适用：授权 CAI/CTF 靶场、离线挑战和用户提供的题目。

流程：
1. 明确题目、范围、目标和停止条件；先用 Knowledge Agent 获取相关背景。
2. 让匹配的 Agent 读取题目文件或服务信息，记录原始输出，不猜 flag。
3. 每次利用只验证一个假设；成功必须保留命令、响应、时间和 flag 证据。
4. 失败时说明失败原因并调整路线，禁止扩大到未授权目标。
5. 最终输出解题链、关键证据、验证结果、未决问题和安全建议。

验收：flag 或失败原因可复核；所有外部动作都在授权范围内。
