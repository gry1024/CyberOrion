# 服务侦察

1. 从目标清单读取主机，不臆造地址；对每个目标先调用一次 `nmap_scan(target, "top100")`。
2. 根据场景已知端口或首轮结果，最多再做一次指定端口扫描；不要无目的扩大端口范围。
3. 把开放端口、服务和失败原因写入 `write_key_findings`；草稿板不可用时保留在当前结论。区分“端口开放”与“已经失陷”。
4. HTTP 服务转入 `web_exploitation` 或 `web-auth-testing`；SSH 服务转入 `ssh-intrusion`。
5. 所有目标已覆盖或连续两次无新增结果时停止侦察，输出下一步优先级。

只通过 `nmap_scan` 接触网络；扫描失败或显示降级探测时如实保留限制，不把超时或未覆盖端口当作关闭。
