# 异常进程狩猎

1. 威胁猎人用 `process_audit(host)` 查看基线新增和可疑标记；只有需要完整上下文时再调用一次 `full=true`。
2. 记录 PID、完整命令行和基线差异，用已有告警或文件证据判断是否与攻击相关；进程名相似不能单独定恶意。
3. 对已经确认的恶意 PID 由威胁猎人统一调用 `remediate(host, "kill_process", pid)`，读取 TERM/KILL 与消失复查结果，避免其他角色重复处置。
4. 处置后重新执行一次 `process_audit`；若进程重生，记录持久化迹象并请求检查文件、cron 或账户，不反复 kill。
5. 无法确认时保持观察并交给研判角色，不终止系统关键进程。

结论必须区分“可疑”“已确认”“已清除”和“再次出现”。
