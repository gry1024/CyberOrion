# 流量分析 Skill

适用：PCAP 摘要、HTTP/DNS/TLS 日志、认证日志和网络告警。

先调用 Knowledge Agent 查询协议异常、攻击技术和检测背景，再调度网络分析 Agent。
按连接、会话、时间窗和资产聚合证据；优先保留五元组、URI、状态码、用户、哈希、
时间戳和原始文件位置。把规则命中与模型推断分开，无法确认的 C2、横向移动或持久化
必须标记为待验证。最终交付流量摘要、可疑序列、证据表、ATT&CK 映射和下一步采集建议。
