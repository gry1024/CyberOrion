# 威胁分析 Skill

先调用 Knowledge Agent 获得带来源的背景报告，再按任务调度 DFIR、Network Security
Analyzer、Reverse Engineering Agent 或 Web Pentester。每条判断分为已证实、合理推断、
未验证；记录来源、时间、资产、置信度和缺失证据。不要把 ATT&CK、CVE、组织归因或
知识库描述当成当前环境事实。交付威胁摘要、证据链、影响、检测点、处置优先级和复核步骤。
